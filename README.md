The Catering Co. 🍽️

A modern website for catering services, events, and delicious food.

The Catering Co. is a web development project designed to give a catering business a professional online presence and help potential customers discover its services.

✨ Features

- Responsive website design for desktop and mobile.
- Professional presentation of catering services.
- Attractive layout showcasing the business.
- Customer enquiry and contact options.
- Clear navigation for a better user experience.

Features should be adjusted to match what is actually implemented in the website.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
